# Global System Artifacts

This directory contains the high-level analysis and design artifacts that apply to the entire **AISafe Flight Management System**, spanning across all Work Packages (WP#1, WP#2, and WP#3).

## Contents

* **[Domain Model Analysis](analysis.md):** Defines the core business rules, constraints, and operational logic (e.g., concurrency control, location validity) governing the domain.
* **[Glossary](glossary.md):** The ubiquitous language of the project, defining all entities, value objects, and business concepts to ensure consistency between the business and the code.
* **[Supplementary Specification](supplementary-specification.md):** Details the Non-Functional Requirements (NFRs) using the FURPS+ model, including architectural constraints, security, and performance metrics.
* **[Global Use Case Diagram](use-case-diagram.md):** The high-level visual representation of system actors and their interactions with the major system modules.
